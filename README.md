# 🍊 Rasilo Suntala - Orange Farm Management Website

## About the Project
This is a complete website for Rasilo Suntala, an organic orange farm in Makpa, Nepal. The website includes:
- Customer-facing homepage with product catalog and order form
- Admin dashboard for order management
- Blog section with multilingual farm updates
- Gallery section with image slider
- Responsive design for all devices

## Features
✅ **Multilingual Support** (Nepali, English, Bhojpuri)  
✅ Custom logo integration with animations  
✅ Full-screen hero section with zoom animation  
✅ About modal with farm information and developer credit  
✅ Product catalog with quantity badges  
✅ Order form with delivery time preferences  
✅ Admin dashboard with password protection  
✅ Order status tracking (Pending/Delivered)  
✅ Summary statistics (5 cards in horizontal layout)  
✅ Order amounts and sold amounts tracking  
✅ Blog posts with multilingual descriptions  
✅ Gallery with image slider and swipe support  
✅ Mobile-responsive design  
✅ Smooth animations and transitions
